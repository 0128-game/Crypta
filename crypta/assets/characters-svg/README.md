# 自分で編集できる、キャラクターの SVG

ゲームに入っている絵を、1枚ずつの SVG ファイルにしたものです。
絵を描くのが、苦手でも、**形や色を、直すだけ**で、自分の絵にできます。

## 編集のしかた
1. 無料の、ベクター編集ソフト（Inkscape、Figma、Affinity Designer、Illustrator など）で、開く。
2. 髪・服・帽子・小物の、**色**を、変える。形を、直したいときは、点（アンカー）を、動かす。
3. 顔の部品（目・まゆ・口）は、1つずつ、独立した図形なので、動かしたり、置き換えたりできる。
4. 保存は、SVG のまま。

## ゲームで使うには
1. 編集した SVG を、`assets/characters/` に置く。
2. `content/characters.json` の、ファイル名を、`.svg` に書き換える（例: `"normal": "alice.svg"`）。
3. ブラウザで、強制再読み込み（Ctrl+Shift+R）。

※ 背景は、もともと、透明です。画像（PNG）と、同じように、チェックページ（`characters-check.html`）で、確かめられます。
