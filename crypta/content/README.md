# content フォルダ（文章をまとめた場所）

ゲームに出てくる**すべての文章**は、ここにまとめてあります。文字を書き換えて保存し、ブラウザを再読み込み（Ctrl+Shift+R）すると、反映されます。ゲームの動き（判定・部品・攻撃者の強さ）は、ここにはありません。

## どのファイルで、何を変えるか

| 変えたいもの | ファイル |
|---|---|
| ステージの名前・ひとこと・「起きていること」・解説・ヒント・想定解の解説・クリア後の文章 | `stages/<ステージ名>.json` |
| ステージの頭の「事件」の文章（現実では・起きたこと・スライドの全部） | `stages/<ステージ名>.json` の `demo`（`story` が、スライド） |
| エピローグの文章 | `stages/stage12.json` の `epilogue` |
| 用語集 | `glossary.json` |
| Alice・Bob・Eve・Mallory のセリフ、攻撃者の吹き出し | `dialogue.json` |
| キャラクターの画像の設定 | `characters.json` |
| **上のどれにも入らない、画面の文章**（判定の理由・ボタン・見出し・部品の名前と説明・トップページ・用語集やチェックページの文言） | **`ui-texts.json`** |

## ui-texts.json の使い方（すべての文章を、変えられる）
- 「元の文」: 「新しい文」の形で、並んでいます。**右側（新しい文）だけ**を書き換えます。左側は、変えないでください（見つからなくなります）。
- グループ名の「ページの文章（○○.html）」は、そのページに、直接書かれている文章です。「画面の文章（js/○○.js）」は、プログラムの中に書かれている文章です。
- 文章の中に、名前や数字が、入るものは、「・文の一部」のグループに、固定の部分だけが、細かく分かれて、入っています。
- 3文字以下の、短い言葉（「次へ」「暗号文」など）は、その言葉だけが表示されているときや、記号・数字・英字・ひらがなに、はさまれているときに、置き換わります（別の言葉の一部には、なりません）。
- 同じ言葉が、画面の、あちこちに、出てくるときは、1か所を書き換えると、すべて、変わります。

## 書き方のきまり
- 名前が `_` で始まる項目は、メモです。ゲームは読みません。
- カンマ（,）や引用符（"）をまちがえると、そのファイルは、読み込めません（その場合も、ゲームは、動きますが、書き換えは、反映されません）。
- `{message}` のように `{ }` で囲んだ部分は、ゲームが、そのときの言葉に置き換えます（`dialogue.json` のみ）。
- 用語集の `id` は、ほかの用語が参照する名前です。変えないでください。

## 書き換えられない（あるいは、書き換えにくい）もの
- 絵（キャラクター）の見た目は、文章では、ありません。`characters.json` と、画像で、変えます。
- 1文字だけの言葉（たとえば、「鍵1」の「1」の前の「鍵」以外の、単独の漢字1文字）は、ほかの言葉の一部と区別できないので、書き換えの対象に、していません。
- JavaScript が、使えない環境で出る、「ステージ一覧の表示には、JavaScript が必要です」の、案内は、書き換えの対象外です。
- ゲームの判定の内容（どの攻撃で、どの要件が、満たされるか）は、`stages/<ステージ名>.json` のデータ（文章ではない部分）と、プログラムで、決まっています。

## 場所を変えたとき
`content` フォルダは、`simulator.html` と同じ階層に置いてください。
