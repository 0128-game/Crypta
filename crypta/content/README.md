# content フォルダ（文章をまとめた場所）

ゲームに出てくる文章は、ここにまとめてあります。文字を書き換えて保存し、ブラウザを再読み込み（Ctrl+Shift+R）すると、反映されます。ゲームの動き（判定・部品・攻撃者の強さ）は、ここにはありません。

| ファイル | 中身 |
|---|---|
| `dialogue.json` | キャラクターのセリフ（Alice・Bob・Eve・Mallory） |
| `glossary.json` | 用語集（用語の説明・分類・読めるようになるステージ） |
| `stages/<ステージ名>.json` | 各ステージの文章（名前・ひとこと・解説・クリア後の「分かったこと」「次に考えたいこと」・ヒント・資料の要点・想定解の解説） |

## 書き方のきまり
- 名前が `_` で始まる項目は、メモです。ゲームは読みません。
- カンマ（,）や引用符（"）をまちがえると、そのファイルは読み込めません。そのときは、画面に、お知らせが出ます。
- `{message}` のように `{ }` で囲んだ部分は、ゲームが、そのときの言葉に置き換えます（`dialogue.json` のみ）。
- 用語集の `id` は、ほかの用語が参照する名前です。変えないでください。

## 場所を変えたとき
`content` フォルダは、`simulator.html` と同じ階層に置いてください。
