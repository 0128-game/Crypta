# ② 自分がやること（キャラクター画像を、ゲームに入れる手順書）

この文書は、**あなたが、やること**を、順番に書いた手順書です。**絵を描く作業（線画・色づけ・色の調整）は、1つも、ありません。** 絵は、ChatGPT が作り、整える作業は、ゲームに付けた「自動整形ツール」が、行います。

- 「① ChatGPT への指示書」の全文は、この文書の「付録A」に、入っています（別のファイルを、開かなくても、ここだけで、作業できます）。
- 「③ 画像を組み込んだシステム」で、何をしたかは、「5. システム（③）で、したこと」に、すべて書いてあります。

## 1. 全体の流れ

| 順番 | やること | 場所 | 目安の時間 |
|---|---|---|---|
| 1 | システム（③）を、GitHub に置く | GitHub | 10分 |
| 2 | ChatGPT で、画像を、10枚作る（単純な絵の指示で） | ChatGPT | 1〜2時間 |
| 3 | 画像を、自動整形ツールに入れて、整える | ブラウザ | 10分 |
| 4 | 整えた画像を、`assets/characters/` に置く | GitHub | 10分 |
| 5 | チェックページで、確かめる | ブラウザ | 5分 |
| 6 | ゲームで、見え方を確かめて、必要なら、やり直す | ブラウザ | 15分 |

画像が、まだ、1枚もなくても、ゲームは、これまでどおり、動きます（ゲームに入っている絵が、表示されます）。画像を置いたキャラから、順に、置き換わります。1枚ずつ、置いて、確かめても、かまいません。

## 2. 事前の準備

1. ③のシステム（`crypta-repo.zip`）を、これまでと同じように、リポジトリのルートに展開して、置き換える。
   - 置き換えたら、ゲームを開いて、いつもどおり動くことを、確かめる（ここでは、まだ、ゲームに入っている絵が出ます）。
2. 画像を作れる ChatGPT を、使えるようにしておく。
3. すでにある、Alice の画像（描き込みの多い版）を、見つけておく（プロンプト1で、添付します）。

## 3. 手順（くわしく）

### 手順1　ChatGPT で、画像を作る
1. ChatGPT で、**新しいチャット**を開く。
2. 「付録A」の「プロンプト0」を、貼る。ChatGPT が「了解」と答えたら、次へ。
3. 「プロンプト1」に、**いまある Alice の画像を、添付**して、貼る。出来上がった Alice は、前の版より、**単純**になっているはずです。
4. 「プロンプト2」→「プロンプト3」→…→「プロンプト10」を、**1つずつ**貼る。
5. 1枚できるたびに、「付録B」の「チェックリスト」で、確かめる。気に入らないときは、「付録A」の「言い直しの文」を、同じチャットに貼る。特に、**「まだ、AI が描いたように見える」**ときの、言い直しの文が、あります。
6. 気に入ったら、画像を、**パソコンに、保存**する（画像を、クリックして、ダウンロード）。名前は、ChatGPT が付けたままでよい（ツールで、どのキャラか、選べます）。
7. 10枚、そろうまで、**同じチャット**で、続ける。

**気をつけること**
- 画風が、ずれたときは、チャットを分けずに、「最初の Alice と同じ画風で、作り直して」と頼む。
- 「あわてた顔」で、顔以外も変わったときは、「顔以外は、1ミリも変えないで」と頼む。
- ChatGPT の画像の生成には、1日の回数の制限がある場合があります。制限に達したら、時間をおいて、続きを作ってください。
- **背景**: ChatGPT は、背景を、透明にしてくれることもあれば、してくれないこともあります。透明にならなかったら、「背景を、無地の紫（#FF00FF）で、ぬりつぶして」と頼んでください。紫の背景は、ツールで、自動で、透明にできます（白い背景は、キャラの白い部分と、区別できないので、使わないでください）。

### 手順2　自動整形ツールで、整える
ツールは、次のアドレスで、開きます（③のシステムを置いたあと）。
`https://0128-game.github.io/Crypta/crypta/characters-tool.html`

1. 保存した画像を、ツールの、点線の枠に、**ドラッグ＆ドロップ**する（まとめて、10枚でも、よい）。
2. 1枚ごとの、プルダウンで、**どのキャラの画像か**を選ぶ（ファイル名に、alice などが入っていれば、自動で選ばれます）。
3. 設定を、確かめる（通常は、そのままでよい）。
   - 「背景が、白（などの、べた塗り）のときは、透明にする」: オンのまま。背景の色は、画像の四隅の色から、自動で決まります。背景が、もともと透明な画像は、そのままです。
   - 「許容する色の差」: 背景の、ふちに、色が残るときは、少し、大きく。キャラの、色が薄い部分まで、消えてしまうときは、小さく。
   - 「出力の大きさ」: 横 640px がおすすめ。
   - 「キャラの高さ」: 92%（そのままでよい）。
4. 「整形する」を押す。
5. 「整えたあと」の画像を、確かめる。背景が、市松模様（透明）で、キャラが、中央に、そろっていればOK。
6. 「すべてまとめて保存（zip）」を押す。`characters.zip` が、保存される。

ツールが、してくれること:
- 背景が、べた塗りなら、**透明にする**。
- 絵の、まわりの、**余白を、けずる**。
- 4:5 の、同じ大きさの枠に、**キャラを、中央に、同じ高さで、そろえて**入れる。（「ふつうの顔」と「あわてた顔」は、同じ切り抜き・同じ拡大にするので、顔以外が、ずれません）
- 横 640px に、**軽くする**（1枚あたり、数十〜百数十KB）。
- `alice.png` などの、**ゲームが読める名前**を付けて、zip にまとめる。

### 手順3　GitHub に置く
1. `characters.zip` を、**展開**する（中に、`alice.png` など、最大10枚の画像が、入っています）。
2. GitHub の、リポジトリを開く。`crypta` フォルダの中の、`assets` → `characters` フォルダを、開く。
3. 「Add file」→「Upload files」を押す。
4. 展開した、画像を、**まとめて、ドラッグして、落とす**（画像ファイルを、直接。フォルダごと、では、ありません）。
5. 下の「Commit changes」を押す。
6. 1〜2分、待つ。

※ 過去に、フォルダ構成が、こわれたときは、「ファイルを、フォルダごとドラッグ」することが、大事でした。今回は、`assets/characters` フォルダを、**開いた状態で**、画像だけを、アップロードしてください。

### 手順4　チェックページで、確かめる
1. 次のアドレスを、開く: `https://0128-game.github.io/Crypta/crypta/characters-check.html`
2. **Ctrl+Shift+R**（強制再読み込み）を、押す。
3. 見る場所:
   - いちばん上の、まとめ: 「10 / 10 枚が、読み込めました」と、出ていれば、OK。
   - 「直したほうが、よい点」の、黄色い枠: 出ていれば、書いてあることを、直す。（出ていなければ、問題なし）
   - 画像1枚ずつの、カード: 「読み込めた」「背景が、透明」「サイズ」「重さ」が、すべて、緑なら、OK。
   - 「ゲームの中での、見え方」: 実際に使われる大きさで、3つのゾーンの色の上に、置いた見え方が、出ます。

### 手順5　ゲームで、見え方を確かめる
次の場面で、見てください。

| 見たいもの | どこで見るか |
|---|---|
| Alice・Bob の顔 | どのステージでも、画面の左と右の、Alice・Bob の部品 |
| あわてた顔（Alice・Bob） | ステージ5 などで、攻撃で、書き換えられたデータが、Bob に届いたとき。または、Bob に届かなかったとき |
| Eve・Mallory | ステージ6 などで、「シミュレーション開始」を押す。公開ゾーンを、歩いて、調べる |
| あわてた顔（Eve・Mallory） | 守りが、効いて、攻撃が、防がれたとき |
| 正体不明の攻撃者・ロボット | ステージ12（エピローグ）。「エピローグを始める」を押して、最後まで、見る |

### 手順6　やり直し・微調整（必要なときだけ）
- **まだ、AI っぽい** → ChatGPT に、「まだ、AI が描いたように見える」の、言い直しの文を、貼る。作り直した画像は、手順2〜3 で、もう一度、整えて、同じ名前で、上書きする。
- **キャラが、ゲームの中で、小さく見える・位置がずれる** → 設定ファイル `content/characters.json` の、そのキャラの `scale`（大きさの倍率）、`offsetY`（上下の位置。％。マイナスで、上へ）を、書き換える。書き換えたら、Ctrl+Shift+R。
- **画像の差し替え** → 同じ名前で、上書きして、アップロード。Ctrl+Shift+R。
- **どうしても、気に入らないキャラだけ** → そのキャラの、`normal`（と `worried`）を、`""`（空）にすると、ゲームに入っている絵（SVG）に、戻る。

## 4. うまくいかないとき

| 症状 | 原因と、直し方 |
|---|---|
| 画像を置いたのに、ゲームの絵が、変わらない | ①ファイル名が、違う（大文字・小文字も）。②置き場所が、違う（`crypta/assets/characters/`）。③ブラウザが、古いものを、見せている → Ctrl+Shift+R。④公開ページの更新に、1〜2分かかる。チェックページで、「見つかりません」と出るキャラを、見る |
| キャラの後ろに、色の四角（白・紫）が、見える | 背景が、透明に、なっていない。ツールの「背景が、白（などの、べた塗り）のときは、透明にする」が、オフか、「許容する色の差」が、小さすぎる。もう一度、整形する |
| 整形すると、キャラの白い部分（シャツ・白目）が、消えた | 「許容する色の差」が、大きすぎる。小さくして、もう一度、整形する。それでも消えるときは、背景を、紫にして、作り直してもらう |
| 整形すると、キャラの、まわりに、紫や白の、ふちが、残る | 「許容する色の差」を、少し、大きくする（40〜60）。それでも残るときは、背景が、グラデーションや、影になっている。「背景を、無地の紫で、ぬりつぶして」と、頼み直す |
| ツールで、キャラの選び方が、分からない | ChatGPT の画像は、名前が、不規則です。画像を、見て、プルダウンで、選ぶ（表の「キャラ」の欄を、見る） |
| 一部のキャラだけ、ゲームの絵のまま | その画像が、読み込めていない。チェックページで、そのキャラが、「見つかりません」になっていないかを、見る |
| あわてた顔が、出ない | `worried` の画像が、ないか、名前が違う。ない場合は、ふつうの顔が、そのまま出ます（エラーでは、ありません） |
| ゲームが、まったく、動かない | `content/characters.json` の、書き方（カンマ・引用符）が、まちがっている。その場合も、ゲームは、動きますが、画像は、使われません。書き方を、直す |
| 絵の「AI っぽさ」が、どうしても、消えない | 完全には、消えないことも、あります。指示を、「もっと単純に」と強めても、変わらないときは、キャラを、人の顔ではなく、**記号のような絵**（耳とヘッドホン、ペンを持つ手、光る目）に、する案もあります。相談してください |

## 5. システム（③）で、したこと（すべて）

画像を、使えるようにするために、ゲームに、したことの、全部です。**ゲームの判定（ステージ・攻撃・評価）や、文章は、1つも、変えていません。** 変えたのは、キャラクターの絵の出し方と、画像を整える道具だけです。

### 5-1. 増やしたファイル
| ファイル | 役割 |
|---|---|
| `content/characters.json` | 画像の設定（ファイル名・大きさ・位置・背景の設定）。あなたが、書き換えられる |
| `assets/characters/README.md` | 画像を置く場所と、置くファイルの説明（ここに、画像を置く） |
| `assets/characters-svg/`（SVG 10枚と README） | ゲームに入っている絵を、1枚ずつの SVG として、書き出したもの（絵を描かなくても、形や色を、直して使いたいときの、材料） |
| `characters-check.html` / `css/characters-check.css` / `js/characters-check.js` | 画像の、**チェックページ** |
| `characters-tool.html` / `css/characters-tool.css` / `js/characters-tool.js` | 画像の、**自動整形ツール** |
| `docs/1_chatgpt-prompt.md` | ①ChatGPT への指示書 |
| `docs/2_your-steps.md` | ②この文書 |

### 5-2. 書き換えたファイル
| ファイル | 変えたこと |
|---|---|
| `js/characters.js` | 画像で表示する仕組みを、足した。画像がないとき・読み込めないときは、これまでの SVG の絵に、切り替える |
| `js/simulator.js` | ゲームを始めるときに、`content/characters.json` を読み込むようにした（読み込めなくても、ゲームは、動く） |
| `css/simulator.css` | 画像のキャラの、表示と、表情の切り替えの、設定を、足した |
| `simulator.html` | 画像が、1枚でも見つからないときに、画面に「エラーが起きました」と出てしまう不具合を、直した（画像がなければ、ゲームの絵に切り替わるだけで、エラーは、出ない） |

### 5-3. ゲームでの、画像の動き（細かく）
1. **設定を読む**: ゲームを始めるとき、`content/characters.json` を、読み込む。読み込めなかったときは、画像を使わず、これまでの絵（SVG）で、動く。
2. **画像で表示する**: キャラに、画像の指定があれば、「ふつうの顔」と「あわてた顔」の、2枚の画像を、重ねて持つ。ふつうの顔だけが、見える。
3. **あわてた顔の、切り替え**: 次のときに、あわてた顔に切り替わる（これまでの SVG の絵と、同じ条件）。
   - Alice・Bob: 部品に、攻撃で書き換えられたデータが届いたとき／届かなかったとき／攻撃を「見抜いた！」ときや、悪い結果の吹き出しが出ているとき。
   - Eve・Mallory: 吹き出しが、守る側にとって、良い結果（攻撃が防がれた）を、出しているとき。
   - 「正体不明の攻撃者」と、ロボットは、あわてた顔は、ありません。
4. **画像がないとき**: キャラごとに、判断する。そのキャラの画像が、見つからない・読み込めないときは、そのキャラだけ、これまでの SVG の絵を、使う。ほかのキャラは、画像のまま。
5. **あわてた顔だけ、ないとき**: ふつうの顔を、そのまま、使う。エラーには、ならない。
6. **大きさ・位置の調整**: `scale`（倍率）と `offsetY`（上下の位置）で、画像ごとに、調整できる。
7. **背景の設定（暫定）**: `blend` を `"multiply"` にすると、白い背景の画像が、なじむ（自動整形ツールで、透明にできるので、通常は、使わない）。
8. **画像の、収まり方**: 画像の、縦横比を、くずさず、決まった枠の中に、収める（引き伸ばさない）。表示する枠の大きさは、Alice・Bob の部品で、横58×縦74、攻撃者で、横112×縦143。
9. **使うのを止める**: `useImages` を `false` にすると、画像を使わない。
10. **エピローグ**: 「???」が、ロボットに変わる場面では、`ai.png` を、`robot.png` に、入れ替える（ない場合は、これまでの SVG の絵）。
11. **ブラウザのキャッシュ**: 設定ファイルは、毎回、読み直す。画像は、ブラウザが、覚えるので、差し替えたときは、Ctrl+Shift+R。

### 5-4. 自動整形ツール（`characters-tool.html`）の機能
- 画像は、ネットに送らず、**ブラウザの中だけで**、処理する。
- ドラッグ＆ドロップ（またはクリック）で、複数枚を、同時に、読み込める。
- ファイル名から、キャラを、推測する（alice・bob・eve・mallory・robot・ai、あわてた＝worried など）。分からないときは、プルダウンで、選ぶ。
- **背景を、透明にする**: 四隅の色を、背景の色として、画像のふちから、つながる部分だけを、透明にする。キャラの中の、同じ色（白いシャツ・白目）は、残る。胸から上の絵で、下の端に、白いシャツが、触れていても、消えないようにしてある。ふちの、にじみも、少し、薄くする。背景が、もともと透明な画像は、そのままにする。
- **余白を、けずって、枠に、そろえる**: 絵の見えている範囲を、測って、4:5 の枠に、中央（胸から上の絵は、下の端）にそろえて、入れる。「キャラの高さ」の割合は、変えられる。
- **ふつうの顔と、あわてた顔を、ずれないようにする**: 同じキャラの2枚は、同じ切り抜き・同じ拡大にする。
- **軽くする**: 横 512 / 640 / 768 ピクセルから選ぶ。
- **保存**: 1枚ずつ、または、すべてまとめて、zip（`alice.png` などの、ゲームが読める名前）で、保存する。zip は、ブラウザの中で、作る（外部の道具は、使っていない）。

### 5-5. チェックページ（`characters-check.html`）の機能
- 設定ファイルに書いてある、全画像（最大10枚）が、読み込めるかを、調べて、「○ / ○ 枚が、読み込めました」と、まとめる。
- 画像1枚ごとに、読み込めたか・大きさ・縦長か・**背景が、透明か**・ファイルの重さ、を、表示する。
- 透明な部分が、見えるように、市松模様の上に、画像を、表示する。
- 「直したほうが、よい点」を、黄色い枠で、まとめる。
- 「ゲームの中での、見え方」を、実際の大きさで、3つのゾーンの色の上に、表示する。

### 5-6. 確かめたこと
- **試しの画像**（図形に文字を入れただけの、仮の画像。使い終わったので、削除済み）で、ブラウザで、次を確かめた。
  - Alice・Bob が画像で表示され、あわてた顔に切り替わる。
  - 画像がないキャラだけ、ゲームの絵に切り替わる。
  - 自動整形ツール: 白い背景を透明にする／下の端に触れている白いシャツが、消えない／もともと透明な画像は、そのまま／ふつうとあわてた顔の、位置が、そろう／キャラが決まっていない画像は、飛ばす／zip が、壊れていない。
  - チェックページが、背景の透明・白・縦横比の違いを、正しく、見分ける。
  - 画像が、まったくないときも、ゲームの全ステージと、エピローグが、これまでどおり動く。
- **あなたの Alice の画像**（描き込みの多い版）を、仮に、ゲームに入れて、部品の大きさ・攻撃者の大きさでの、見え方を、確かめた（そのとき、上の「エラー表示」の不具合を、見つけて、直した）。
- **確かめていないこと**: ChatGPT が作る、**単純な絵の版**の、見た目（まだ、ないため）。実際の画像を、置いたあとに、手順4・5 で、確かめてください。スマホでの、見え方も、確かめていません。
