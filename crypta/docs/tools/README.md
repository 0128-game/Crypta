# docs/tools（道具）

## 管理者モード（管理者用のツールの、入り口）
管理者用のツールは、**トップページ（index.html）の、いちばん下の文**から、入ります。

1. トップページを、いちばん下まで、スクロールする。
2. 「CRYPTA は暗号と情報セキュリティを学ぶための教材ゲームです。」の文を、**すばやく 7 回、クリック**する（4秒以内）。
3. **合言葉**を、聞かれる（いまは「**Administrator**」）。合言葉を変えるときは、`content/admin.json` の `passcode` を、書き換える（空 `""` にすると、合言葉なし）。
4. 「管理者用ツール」の画面が、開く。いちばん下に、「管理者モード」の札も、出る。

- 管理者モードは、**このタブの中だけ**です。**トップページを、開き直す（再読み込み・戻る）と、終わり**、札も、消えます。タブを閉じても、終わります。
- 注意: このゲームは、サーバーのない、静的なページです。入り口の、隠し方や、合言葉は、**うっかり、開いてしまうのを防ぐもの**で、本当の、アクセス制限では、ありません。合言葉は、`content/admin.json` に、そのまま、書かれていて、だれでも、読めます。大事な情報は、入れないでください。

### 管理者センター（`admin.html`）
管理者用の、すべての機能を、1か所に、まとめたページです。

| 機能 | できること |
|---|---|
| **crypta.zip のダウンロード** | 「変更前」（いまのファイルのまま）／「変更後」（この端末の、試しの変更を、反映）／「両方」（before と after の、2つのフォルダ）。展開した crypta フォルダを、そのまま、GitHub などに置ける |
| ロゴ | 置いてある画像の確認。画像を選んで、この端末だけで、試す |
| ステージの開閉と、進み具合 | ステージごとに、クリア済み・評価を、設定。全ステージの解放（確認用）。**想定解ボタンを、最初から出す**。各ステージを、直接、開く |
| 試し用の設定 | 「試し」で、使っている、セリフ・名前・CSS・ロゴを、確認して、消す |
| バックアップ | 進み具合・保存した回路を、ファイルに、書き出す・読み込む |
| ファイルの点検 | すべてのファイルが、あるか、JSON の書き方に、まちがいがないかを、調べる |
| 情報 | ファイル数・ステージ数・セリフの数・用語の数など |

「変更後」の zip には、次の、試しの内容が、入ります（この端末の中の、「試し」で、保存したもの）。
- セリフ・名前（セリフ・名前の編集画面で、「ゲームで試す」）→ `content/dialogue.json` / `names.json`
- CSS（`css-preview.html` の、「ゲームで試す」。サイトの中の、css-preview.html を、開いたとき）→ `css/theme.css`
- ロゴ（管理者センターで、画像を選んで、試す）→ `assets/logo.png` など、と `content/logo.json`

### ロゴを、画像にする
- ロゴの画像を、`assets/logo.png`（または `logo.svg` / `logo.webp`）に、置くと、すべてのページの、左上のロゴが、画像になります。**画像が、ないときは、元の文字のロゴ**です。
- 大きさや、候補の名前は、`content/logo.json` で、変えられます（`height` = 高さ）。
- 背景が、透明な、PNG か SVG が、おすすめです。

### 何が、画面から、編集できるか（文章の編集 `dialogue-editor.html`）
| タブ | 対象ファイル | 内容 |
|---|---|---|
| セリフ | `content/dialogue.json` | キャラクターのセリフ（60個） |
| 名前 | `content/names.json` | アリス・ボブ・イブ・マロリーの名前 |
| ステージの文章・スライド | `content/stages/*.json` | ステージ名・目標・ヒント・事件の説明スライド（ページの追加・削除・並べ替え）など |
| ブロックの説明 | `content/parts.json` | ブロックの説明（途中のステージから変える） |
| 用語集 | `content/glossary.json` | 用語の、追加・削除・書き換え |
| 画面の文章 | `content/ui-texts.json` | ボタン・見出しなど、画面に出る、すべての文章（約830個） |
| 設定（上級） | `stages/*.json` | ステージの設定（使える部品・想定解・攻撃者・条件・通数など）を、JSON のまま、書き換える |

### 編集した内容は、どこに、保存されるか
- 編集画面で、書き換えると、**この端末のブラウザの中（localStorage）に、自動で、保存**されます（フォルダには、入りません）。「全ステージをリセット」や、「進み具合を消す」を押しても、**書きかけは、消えません**。
- ただし、別のブラウザ・別のパソコン・別のアドレス（localhost と GitHub Pages など）では、見えません。ブラウザの「サイトデータを消す」でも、消えます。
- ファイルにして残すには、各タブの「**ダウンロード**」（そのタブのファイル1つ）、または「**変更をまとめてダウンロード**」（変更したファイルすべてを、1つの zip に。展開して、`crypta` フォルダの、同じ場所に、置き換える）を押します。ステージの選択肢には、変更したステージに「● 変更あり」の印が付きます。
- まとめて残すには、管理者センターの「crypta.zip のダウンロード」の「**変更後**」（自動保存した書きかけも、含みます）か、「バックアップ」の「書き出す」（書きかけも、含みます）を使います。

画面から、編集できないもの（ファイルや、コードの、書き換えが必要）:
- キャラクターの絵（`js/characters.js`。画像にするときは `content/characters.json` と `assets/`）
- 判定のしくみ・計算にかかる時間（ms）の値（`js/engine.js`）
- CSS は、`css-preview.html`（`css/theme.css` だけ）。`common.css` / `simulator.css` は、対象外です
- 管理者モードの合言葉（`content/admin.json`）・ロゴの設定（`content/logo.json`）は、ファイルを、直接、書き換えます

画面の文章（`ui-texts.json`）に、新しい文章を、足したいとき（プログラムに、新しい画面の文章を、足したあと）は、`python docs/tools/make_ui_texts.py` を実行します（書き換え済みの文章は、残ります）。

### 事件・実演の、「戻る」
- 実演（事件・シミュレーション）は、常に、手動です。「次へ」（またはスペース・Enter）で、進みます。
- 「**戻る**」（「次へ」の左）: ひとつ前の手順に、戻ります（最初から、素早く、やり直して、ひとつ前で、止まります）。
- 事件の説明の、1ページ目の「**もう一度、見る**」: 事件の動きを、最初から、見直します。2ページ目以降は、「戻る」で、前のページに、戻れます。
- ツールバーの「**事件の前の回路に戻す**」（前のステージの回路を、引き継ぐステージだけ）: 盤面を、事件のときの回路（前のステージで、組んだ回路）に、戻します。「元に戻す」で、取り消せます。

### ゲームの中の、編集（右クリックと、元に戻す）
- ブロックを、**右クリック**: 「複製」（つながっている線も、同じ相手から、つなぐ）・「ブロックを削除」。
- 線を、右クリック: 「線を削除」だけ。
- 何もない所を、右クリック: 「整頓させる」・「全消去」。
- **元に戻す・やり直し**: 画面の、ボタン、または、Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）。部品を動かしたことも、元に戻せます。
- 「やり直す」ボタンは、「**最初から**」に、名前を変えました（回路を、最初の状態に、戻す）。

### ステージの一覧
解放前のステージは、トップページに、**存在ごと、出ません**（番号も「？？？」も、出ません。そのステージの、見出しも、出ません）。管理者センターの「全ステージを解放」を、オンにすると、すべて、見えます。

### ファイルの一覧（`content/files.json`）
zip のダウンロードと、ファイルの点検は、ファイルの一覧を、使います。ファイルを、**足したり、消したりしたら**、`python docs/tools/make_manifest.py` を、実行して、一覧を、作り直してください（ロゴの画像は、一覧になくても、自動で、探します）。

### 新しい道具を、足すとき
`js/admin.js` の `TOOLS` の一覧に、1行、足します。

### 「ゲームで試す」の、仕組み
セリフ・名前・CSS を、書き換えて、「ゲームで試す」を押すと、**このブラウザの中だけ**に、試し用の内容が、保存されます（`localStorage`）。管理者モードのあいだだけ、ゲームは、それを使い、画面の左下に、黄色い札が出ます。ふつうのプレイヤーには、影響しません。確かめたら、「保存」（または、管理者センターの zip）で、ファイルに、して、`content` などのファイルを、置き換えます。

## css-preview.html（CSS のプレビュー）
`crypta/css-preview.html` を、ダブルクリックで、ブラウザに、開きます（サーバーは、いりません。1枚で、完結しています）。

- **左**: `css/theme.css` の内容。書き換えると、**右の部品に、すぐ、反映**されます。
- **右**: ゲームで、実際に使われている部品（ボタン・ブロック20種類・攻撃者と吹き出し・ボード・結果・事件の説明・用語集など）を、そのまま並べたもの。
- 右の部品を、**クリック**すると、その部品の、クラス名が出て、左の CSS の、その場所が、選ばれます。
- 上の「画面の幅」で、スマホ・タブレット・PC の幅を、切り替えられます（その幅で、ゲームと同じ、レイアウトの切り替えが、働きます）。
- 気に入ったら、「保存（theme.css）」または「コピー」で、`css/theme.css` を、置き換えます。「元に戻す」で、開いたときの状態に、戻ります。

### CSS を変えたあと（css-preview.html を、最新にする）
ゲームの `css/` を、直接、書き換えたときは、プレビューにも、反映させます。
1. `python docs/tools/make_css_preview.py`

### ゲームの画面の作り（HTML）を変えたあと
部品の、取り出し直しが、必要です。
1. `crypta` フォルダで、`python -m http.server 8765` を起動。
2. `python docs/tools/capture_gallery.py`（Playwright が必要）
3. `python docs/tools/make_css_preview.py`

## make_ui_texts.py
画面の文章を、すべて書き換えられる `content/ui-texts.json` を、作り直します（書き換え済みの文章は、残ります）。
