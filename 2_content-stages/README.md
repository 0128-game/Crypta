# 2_content-stages（データと文章を、1つにまとめた場所）

ゲームに出てくる**すべての文章**と、ステージの設定は、`crypta.json` の**1つのファイル**にまとめてあります（表面・裏面の両方）。文字を書き換えて保存し、ブラウザを再読み込み（Ctrl+Shift+R）すると、反映されます。ゲームの動き（判定のしくみ）は、プログラムの中にあります。

## crypta.json の中の、まとまり

| まとまり | 中身 |
|---|---|
| `dialogue` | Alice・Bob・Eve・Mallory のセリフ。`atk` は裏面（攻撃者モード）の文章とセリフ |
| `names` | キャラクターの名前（画面の、すべての文章で、置き換わる） |
| `ui-texts` | 上のどれにも入らない、画面の文章（ボタン・見出し・判定の理由・裏面の画面の文字など）。「元の文」: 「新しい文」 |
| `glossary` | 用語集 |
| `parts` | ブロックの説明（途中のステージから変える分） |
| `characters` / `logo` / `admin` | キャラクターの画像の設定・ロゴ・管理者モードの合言葉 |
| `files` | ゲームの、すべてのファイルの一覧（`3_docs/tools/make_manifest.py` で、作り直す） |
| `stageTexts` | 表面のステージごとの文章（`stage01` 〜 `stage12`・`test`） |
| `stages` | 表面のステージごとの設定（使える部品・攻撃者・判定・想定解）。文章ではない |

## 何を変えたいときに、どこを書き換えるか

| 変えたいもの | ファイル |
|---|---|
| ステージの名前・ひとこと・「起きていること」・解説・ヒント・想定解の解説・クリア後の文章 | `stageTexts` の `<ステージ名>` |
| ステージの頭の「事件」の文章（現実では・起きたこと・スライドの全部） | `stageTexts` の `<ステージ名>` の `demo`（`story` が、スライド。破られ方が、ふつうと違うステージは、`bannerBad`＝大きな見出し、`verdictBad`＝結果の見出し、を足せる。例: ステージ11） |
| エピローグの文章 | `stageTexts` の `stage12` の `epilogue` |
| 用語集 | `glossary` |
| Alice・Bob・Eve・Mallory のセリフ、攻撃者の吹き出し | `dialogue` |
| セリフ・名前を、**画面で**、書き換える | 管理者モードの「セリフ・名前の編集」（`dialogue-editor.html`。入り方は、`docs/tools/README.md`） |
| ブロックの説明を、**途中のステージから**、変える | `parts`（管理者モードの「文章の編集」の「ブロックの説明」でも、編集できる） |
| 管理者モードの合言葉（いまは Administrator） | `admin` |
| ロゴの画像の場所・高さ | `logo`（画像は、`assets/logo.png` などに置く。ないときは、元の文字のロゴ） |
| **キャラクターの名前**（アリス・ボブ・イブ・マロリー） | **`names`**（右側だけを書き換える。画面の、すべての文章で、一度に、置き換わる） |
| キャラクターの画像の設定 | `characters` |
| **上のどれにも入らない、画面の文章**（判定の理由・ボタン・見出し・部品の名前と説明・トップページ・用語集やチェックページの文言） | **`ui-texts`** |

## ui-texts の使い方（すべての文章を、変えられる）
- 「元の文」: 「新しい文」の形で、並んでいます。**右側（新しい文）だけ**を書き換えます。左側は、変えないでください（見つからなくなります）。
- グループ名の「ページの文章（○○.html）」は、そのページに、直接書かれている文章です。「画面の文章（js/○○.js）」は、プログラムの中に書かれている文章です。
- 文章の中に、名前や数字が、入るものは、「・文の一部」のグループに、固定の部分だけが、細かく分かれて、入っています。
- 3文字以下の、短い言葉（「次へ」「暗号文」など）は、その言葉だけが表示されているときや、記号・数字・英字・ひらがなに、はさまれているときに、置き換わります（別の言葉の一部には、なりません）。
- 同じ言葉が、画面の、あちこちに、出てくるときは、1か所を書き換えると、すべて、変わります。

## 書き方のきまり
- 名前が `_` で始まる項目は、メモです。ゲームは読みません。
- カンマ（,）や引用符（"）をまちがえると、そのファイルは、読み込めません（その場合も、ゲームは、動きますが、書き換えは、反映されません）。
- `{message}` のように `{ }` で囲んだ部分は、ゲームが、そのときの言葉に置き換えます（`dialogue` のみ）。
- 用語集の `id` は、ほかの用語が参照する名前です。変えないでください。

## 書き換えられない（あるいは、書き換えにくい）もの
- 絵（キャラクター）の見た目は、文章では、ありません。`characters` と、画像で、変えます。
- 1文字だけの言葉（たとえば、「鍵1」の「1」の前の「鍵」以外の、単独の漢字1文字）は、ほかの言葉の一部と区別できないので、書き換えの対象に、していません。
- JavaScript が、使えない環境で出る、「ステージ一覧の表示には、JavaScript が必要です」の、案内は、書き換えの対象外です。
- ゲームの判定の内容（どの攻撃で、どの要件が、満たされるか）は、`stages` のデータと、プログラムで、決まっています。

## 場所を変えたとき
`content` フォルダは、`simulator.html` と同じ階層に置いてください。

## 裏面（攻撃者モード）の文章
- ステージの説明・したいこと・状況・成功したときの文・止め方・エピローグ・Alice と Bob のセリフは、`dialogue` の `atk` にあります（管理者モードの「文章の編集」の「裏面（攻撃者モード）の文章とセリフ」でも、書き換えられます）。
- 裏面の、ボタン・コマンド名・通知・持ち物の名前など、そのほかの文字は、`ui-texts` の「画面の文章（js/atk-play.js）」「画面の文章（js/atk-scenarios.js）」などに、並んでいます。

## コードや HTML に、新しい文章を足したとき
`python 3_docs/tools/make_ui_texts.py` を実行すると、`ui-texts` に、新しい文章が足されます（書き換え済みの文章は、残ります）。
